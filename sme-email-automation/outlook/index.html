01 / Choose your automatic rule
YOUR RULEIF subject contains “Order” → move to folder “Customer Orders”

This page helps you plan your rule. To activate the automation, follow the setup steps in Outlook below.

Set it up in Outlook

Follow the steps · check each one off

01

Open Outlook

Sign in at outlook.office.com (work or school) or outlook.live.com/mail (personal Outlook.com).

02

Create a destination folder

In the folder list, create a folder named Customer Orders using New folder or the folder context menu.

03

Open the rules settings

Select Settings ⚙ → Mail → Rules → Add new rule. In some versions you can also right-click a message and choose Rules → Create rule.

04

Configure the condition + action

Name the rule Organize customer requests. Set the condition Subject includes Order, and action Move to Customer Orders. Save the rule.

05

Test the result

Have a colleague send an email with the subject Order – test customer enquiry to your Outlook account. Confirm the message appears in the Customer Orders folder.

Test your automation

Verify it really works

Send a test message

Use this subject in an email sent to the account where you created the rule:

Order – test customer enquiry

What success looks like

  • A new test message arrives.
  • The incoming email is moved automatically into your chosen folder.
  • A message without the keyword should not match that rule.

If you use a Gmail account inside the new Outlook app, Microsoft notes that rules for third-party accounts may not be supported. Create the filter directly in Gmail instead. Menu labels may vary slightly by Outlook version.
