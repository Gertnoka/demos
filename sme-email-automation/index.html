1

Create a label

In Gmail’s left sidebar, next to Labels, select Create new label and name it Orders.

2

Create a filter

In the search bar, select Show search options. Enter Order in Subject → Create filter → Apply label: Orders → Create filter.

3

Test the rule

Send a new email to yourself with the subject Order – Workshop Test. Confirm it receives the Orders label automatically.
